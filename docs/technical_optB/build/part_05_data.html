DERIVED הטריק: טבלת lookup בגודל n+1, שהערך האחרון בה תמיד False. במסגרת cell_map=-1, ובפייתון lookup[-1] הוא האיבר האחרון. כך מתקבלת המסכה בפעולת gather אחת, O(N^2), בלי לולאה על תאים. covered_mask מוסיף את ה־perimeter: \mathrm{px}(C)=P\cup\{p:\ \mathrm{cell}(p)\in C\}.
