שלב א: החלקה משמרת קצוות (bilateral)

THEORETICAL BACKGROUND הגדרת cv2.bilateralFilter עם d=9,\ \sigma_c=24,\ \sigma_s=5:
\tilde I(p)=\frac{\sum_{q\in N_9(p)} w_s(p,q)\,w_c(p,q)\,I(q)}{\sum_{q\in N_9(p)} w_s(p,q)\,w_c(p,q)},\quad w_s=e^{-\frac{\|p-q\|^2}{2\sigma_s^2}},\quad w_c=e^{-\frac{\delta(I(p),I(q))^2}{2\sigma_c^2}}

N_9(p) היא סביבה בקוטר 9 פיקסלים. \delta הוא מרחק הצבע. ב־OpenCV, בתמונה בת 3 ערוצים, זהו סכום ההפרשים המוחלטים בין הערוצים (יחידות 0–255). שכן שצבעו שונה מאוד (למשל שחור ליד הצהוב #EAC007, עם \delta=234+191+7=432) מקבל משקל e^{-432^2/(2\cdot 24^2)}\approx 0, ולכן הקצה לא מטושטש. רעש JPEG קטן (\delta\approx 10) מקבל משקל e^{-100/1152}\approx 0.92 ומתמצע.

שלב ב: מעבר ל־Lab וזיהוי פיקסלי פנים

IMPLEMENTED MATHEMATICS שורות 94–97:
G(p)=\sqrt{(S_x * g)(p)^2+(S_y * g)(p)^2},\qquad \text{interior}=\big[\,G<40\,\big]\ominus B_{5\times5}

g היא תמונת האפור של התמונה המוחלקת. S_x,S_y הם גרעיני Sobel בגודל 3×3, והפלט ב־float32. \ominus B_{5\times5} היא שחיקה (erosion) בריבוע 5×5: פיקסל נחשב "פנימי" רק אם בכל ריבוע ה־5×5 סביבו הגרדיאנט נמוך מ־40. כך מוסרים גם פיקסלים שנמצאים עד 2 פיקסלים מקצה.

  53  def merge_small_fragments(labels: np.ndarray, min_pixels: int) -> np.ndarray:
  54      """Relabel each 4-connected fragment below ``min_pixels`` to its dominant neighbor."""
  55  
  56      labels = labels.copy()
  57      for color in np.unique(labels):
  58          components, count = ndimage.label(labels == color)
  59          if not count:
  60              continue
  61          areas = np.bincount(components.ravel())
  62          for index, region in enumerate(ndimage.find_objects(components), start=1):
  63              if areas[index] >= min_pixels:
  64                  continue
  65              y0, y1 = max(region[0].start - 1, 0), region[0].stop + 1
  66              x0, x1 = max(region[1].start - 1, 0), region[1].stop + 1
  67              window = labels[y0:y1, x0:x1]
  68              mask = components[y0:y1, x0:x1] == index
  69              ring = ndimage.binary_dilation(mask) & ~mask
  70              neighbors = window[ring]
  71              if neighbors.size:
  72                  window[mask] = np.bincount(neighbors).argmax()
  73      return labels

לכל צבע, ndimage.label (קשירות 4, ברירת המחדל של scipy) מוצא רכיבים. לכל רכיב F עם |F|<40 מחושבת "טבעת" \partial F=(F\oplus C)\setminus F, כאשר C הוא צלב 3×3, וכל F מקבל את הצבע הנפוץ ביותר בטבעת (bincount().argmax()). העדכון נעשה במקום, ולכן מיזוג מוקדם משפיע על הטבעות של שברים שנבדקים אחריו.
