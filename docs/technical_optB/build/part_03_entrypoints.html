3. נקודות כניסה ורצף הביצוע של Option B

3.1 אין נקודת כניסה אחת

GAP אין במאגר פקודה אחת שהופכת תמונה ל־STL. ל־python -m layerforge_l1 (cli.py) אין קשר למסלול הזה. Option B הופק בשש פקודות. שתיים מהן סקריפטים שנשמרו במאגר, וארבע הן קטעי Python חד־פעמיים שהעוזר הריץ. הקוד המדויק של הקטעים החד־פעמיים מופיע בפרק הזה, כי אין לו עותק אחר במאגר.

pal = np.load('artifacts/l1_van_gogh_v1/palette.npy')

שים לב: הפלטה חושבה ברזולוציה המקורית, אבל המיפוי הסופי בוצע על התמונה המוקטנת. 2048 פיקסלים מייצגים 200 מ"מ, ולכן בתמונת היעד כל פיקסל הוא 200/2048 = 0.09765625 מ"מ, בדיוק כמו ברשת הפיזית. הסבר מלא בפרק 6.

3.5 שלב 3: תיקוני Option A ו־Option B AD HOC · USER-REQUESTED

red = (t == RED).all(-1); left = leftmost 4-connected red component; window = its bbox + 60 px
Y = (t == YELLOW).all(-1)
k = cv2.getStructuringElement(cv2.MORPH_ELLIPSE, (17, 17))           # 17 px = 1.66 mm
thin = Y & ~cv2.morphologyEx(Y, cv2.MORPH_OPEN, k) & window
a = t.copy(); a[thin] = BLACK                                         # Option A
b = a.copy(); b[(b == BAND).all(-1)] = BLACK                          # Option B (BAND = #354043)
