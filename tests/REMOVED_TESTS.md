# Removed and converted tests (L0 cleanup, 2026-10-25)

Before this cleanup, the suite had 97 PASS / 51 FAIL / 0 SKIP
(`$env:PYTHONPATH='src'; .\.venv\Scripts\python.exe -m pytest`). All 51 failures were
`FileNotFoundError`/`StopIteration` on artifact trees that commit `2c375e5` deleted.
The user confirmed that those historical experiment reports are not needed, and they
were **not** restored. The exact removed code is in git history at `789b02a`.

## Classification of the 51 failures

| Class | Count | Action |
|---|---|---|
| 1. Obsolete: only verify deleted historical experiment outputs | 43 | removed (listed below) |
| 2. Valuable: depend on old artifacts unnecessarily | 8 | converted to fixtures regenerated in the test |
| 3. Genuine failures unrelated to missing artifacts | 0 | none found (one latent path bug fixed, see below) |

In addition, **4 vacuous passing tests** were removed. They asserted "no STL/STEP in
`artifacts/<deleted folder>`", which passed only because the folder no longer exists.

- `test_l1_feasibility.py`: T-L03, T-L06, T-L07, T-L08, T-L09, T-L12 now read a module-scoped
